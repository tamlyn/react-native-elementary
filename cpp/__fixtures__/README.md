# Synthetic audio fixtures

No recorded or third-party audio. Each file encodes 0.25 seconds at 48 kHz:
left 440 Hz at 0.4 amplitude, right 880 Hz at 0.2 amplitude. Reused from Midicircuit's
sampler decoder regressions (issue #137).

```sh
ffmpeg -f lavfi -i 'aevalsrc=0.4*sin(2*PI*440*t)|0.2*sin(2*PI*880*t):s=48000:d=0.25' -c:a flac stereo-48k.flac
ffmpeg -f lavfi -i 'aevalsrc=0.4*sin(2*PI*440*t)|0.2*sin(2*PI*880*t):s=48000:d=0.25' -c:a libmp3lame -b:a 192k stereo-48k.mp3
```

FLAC has 12,000 frames; MP3 can include encoder delay/padding. Tests compare chunk
positions within each decoder's output and check pitch away from codec edges.
WAV and boundary fixtures are generated by the test executable.
